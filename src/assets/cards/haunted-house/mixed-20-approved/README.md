# Mixed 20-card approved deck

This directory contains the 17 cards retained after manual review from the 20-card batch.

- The three rejected files were removed during review.
- `generated-*.png` filenames are intentionally neutral so cards can be renamed when they are registered in the runtime artwork manifest.
- `generated-*.png` filenames are intentionally neutral so cards can be renamed after approval.

The batch mixes direct-match and deletion-rule cards. The images are approved artwork assets; runtime registration remains a separate step because each card still needs its exact question specification and answer metadata.
